# 🛍️ Catalogue de produits avec filtres

Projet 8.2 — Akieni Academy — Phase 2 — Semaine 8

##  Présentation

Le **Catalogue de produits avec filtres** est une application web
permettant de manipuler une collection de produits représentés sous
forme d'objets JavaScript.

L'objectif est d'utiliser les méthodes fonctionnelles des tableaux
afin de filtrer, transformer, calculer et trier les données.

Les produits sont ensuite affichés dans une grille responsive.

---

##  Objectifs

Le projet permet de :

- manipuler un tableau d'objets ;
- filtrer des données ;
- transformer des données ;
- calculer une valeur totale ;
- trier un tableau ;
- utiliser le spread operator ;
- utiliser la déstructuration ;
- afficher dynamiquement les produits.

---

##  Compétences JavaScript

Les principales méthodes travaillées sont :

- `map()`
- `filter()`
- `reduce()`
- `find()`
- `sort()`

Le projet travaille également :

- la déstructuration ;
- le spread operator ;
- les tableaux d'objets ;
- les fonctions de transformation.
